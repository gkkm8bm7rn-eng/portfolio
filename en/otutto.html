A website built around the collection

The verified structure contains 22 content pages: home, collection, model pages, production information, and a journal. The collection supports model search, and photographs can be opened at a larger size.

Restrained typography and large images keep the furniture in focus. A dedicated menu supports mobile navigation. The site demonstrates structure and interface; it has no connected inquiry system, cart, or payment flow.

02 / AI sales assistant

From configuration to commercial proposal

A custom GPT uses a product price list to calculate modular sofas, compare fabric and leather categories, and prepare a customer-ready proposal. The buyer can see the difference between finishes immediately — making premium options easier to discuss.

AI sales assistantIllustrated workflow

One continuous conversation, from the first request to the finished document.

Enter parameters

Manager

AI sales assistant

Got it. Two straight modules, one chaise longue, fabric category 3. I'll calculate the configuration and then compare upholstery options.

02 / 05

Calculate the configuration

Manager

Show the price by component.

AI sales assistant

Straight modules: 2 × 58,000 ₽ = 116,000 ₽. Chaise longue: 79,000 ₽. Total with fabric category 3: 195,000 ₽.

03 / 05

Compare materials

Manager

What changes with category 5 fabric or leather?

AI sales assistant

Fabric category 3 — 195,000 ₽. Fabric category 5 — 228,000 ₽. Leather — 288,000 ₽. All three options retain the same module configuration.
