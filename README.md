## Посмотреть до публикации

Распакуйте подготовленный архив `portfolio-stage2-preview.zip` и откройте `portfolio/index.html` в браузере. Все страницы, локальные изображения, шрифты, цены и навигация работают без сборки и сервера. Английская версия — `en/index.html`.

Для проверки в подпапке, аналогичной GitHub Pages, запустите из родительской папки репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/portfolio/`. Имя распакованной папки должно быть `portfolio`; или используйте его фактическое имя в адресе. Для сервера непосредственно из репозитория адрес — `http://127.0.0.1:8000/`.

## Редактирование

- `data/services.json` — единственный источник цен, базового объёма, факторов удорожания и ссылок на примеры, RU/EN.
- `scripts/build.py` — тексты и шаблоны; генерирует готовые страницы в корне и `en/`.
- `studio.css`, `studio.js` — общая визуальная система, адаптивная навигация и доступное модальное меню.
- `cover.css` — только светлая художественная обложка, композиция и переход к тёмно-синей части главной.
- `assets/studio/` — проверенные оптимизированные оригиналы и настоящие скриншоты интерфейсов.
- `data/image-sizes.json` — размеры изображений для стабильной загрузки.

После изменения данных или шаблонов:

```sh
python3 scripts/build.py
python3 scripts/check.py
```

Python 3.9+; сторонние библиотеки для генерации и проверки не нужны. Не редактируйте сгенерированные HTML отдельно от шаблона.
